🌐 Guia de Execução Contínua 24 Horas por Dia

Como manter o sistema rodando ininterruptamente e expor o webhook para a Umov.me

Passo 1: Rodar o processo em segundo plano com PM2 (Auto-Restart)

O PM2 garante que mesmo se ocorrer qualquer erro não tratado ou reinício do servidor, a aplicação sobe novamente sozinha:

npx pm2 start src/server.js --name trade-hub
npx pm2 save

Passo 2: Expor a URL para a Umov.me via Cloudflare Tunnel (HTTPS Grátis 24h)

Para a Umov.me disparar o webhook na sua máquina ou VPS sem precisar abrir portas de roteador:

npx cloudflared tunnel --url http://localhost:3000

A Cloudflare fornecerá uma URL HTTPS segura como https://exemplo-randomico.trycloudflare.com/api/webhook/umovme para colocar no painel da Umov.me!
